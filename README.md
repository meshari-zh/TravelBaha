# TravelBaha 🌴 | منصة دليل السياحة الرقمي لمنطقة الباحة

مشروع تخرج لنيل درجة البكالوريوس في نظم المعلومات الحاسوبية - جامعة الباحة.

---

## 📌 نبذة عن المشروع
منصة رقمية متكاملة تهدف إلى دعم وتسهيل السياحة في منطقة الباحة من خلال تقديم دليل تفاعلي شامل للمواقع السياحية، المعالم، والخدمات المتاحة للزوار.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Frontend / UI:** React, TypeScript, Tailwind CSS
* **Backend / Database:** Node.js, SQL / JSON Database
* **Project Tools:** Vite, PostCSS, Git
